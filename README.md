# Fidelstine Charity Concerns and Orphanage website

Website for Fidelstine Charity Concerns and Orphanage, Ubulu Okiti, Delta State, Nigeria.

- **PLAN.md** is the full build plan: redesign, device layouts, media system and Flutterwave donations.
- **CLIENT-REQUIREMENTS.md** holds everything the client has provided so far.
- **docs/MEDIA-BRIEF.md** tells the charity how to film and photograph for the site.

Setup and development instructions are added to this file as each phase lands.
